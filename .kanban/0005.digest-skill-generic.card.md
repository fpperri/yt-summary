# Digest skill: generic analysis + study guide from a transcript or text

When I have a transcript or text saved (from the ingest skill or pasted), I want a digest skill that produces an analysis and a study guide next to it, so the plugin is useful end-to-end without any cortex machinery.

Inspiration: the cortex `digest-source` skill (shared engine the cortex ingest trio delegates to). Scope caution decided 2026-09-01: do NOT publish the cortex inquiry analysis/study-guide contract — it is mid-redesign (ADR-0020, inquiry-mode-families still open). Design a generic digest format for the public plugin; cortex keeps its own format in its wrapper. HITL checkpoint = agree on that generic format before building.

## Acceptance Criteria
- Digest skill takes a file path or pasted text (no URL fetching — that is the ingest skill's job) and writes analysis + study-guide artifacts beside the source.
- Format is plugin-generic; no `.cortex` references.

Committed `92bb4bc`; the specs are `skills/digest/references/analysis-format.md` and `study-guide-format.md`. (by @assistant)
